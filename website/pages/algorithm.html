Algorithm Purpose & Specification

The CineMetrics algorithm resolves a fundamental search task: given a user's chosen film genre, it sequentially scans the curated IMDb dataset, counts all valid matching titles, compares their numeric ratings, and deterministically outputs the highest-rated movie along with statistical context.

Assignment Requirement Checklist (Step 3):
  • Line Count: Exactly 38 lines of formal pseudocode (well within the mandated 30–50 line range).
  • Variables Defined: target_genre, best_rating, best_movie, genre_count, genre_list, genre_token.
  • Selection: Multiple IF-ELSE constructs (validating inputs, checking genre equality, comparing ratings, and evaluating final counts).
  • Iteration: Nested FOR EACH loops traversing both the 99 movie rows and the comma-delimited genre tokens.
  • Language Demonstration: Provided as formal pseudocode (algorithm/algorithm.md) AND implemented in Turing-complete Python (algorithm.py) with an automated test suite.

Pseudocode Specification (38 Lines)

01: FUNCTION find_highest_rated_movie(dataset, user_genre_query)
02:     // Step 1: Input normalization and sanitization
03:     SET target_genre TO LOWERCASE(TRIM(user_genre_query))
04:     IF target_genre IS EMPTY THEN
05:         PRINT "Error: Genre name cannot be blank. Please enter a valid genre."
06:         RETURN NULL
07:     END IF
08:     
09:     // Step 2: Initialize tracking variables
10:     SET best_rating TO 0.0
11:     SET best_movie TO NONE
12:     SET genre_count TO 0
13:     
14:     // Step 3: Iteration over curated movie records
15:     FOR EACH movie IN dataset DO
16:         SET genre_list TO SPLIT(LOWERCASE(movie.Genre), ",")
17:         
18:         // Step 4: Token-level matching across comma-separated genres
19:         FOR EACH genre_token IN genre_list DO
20:             IF TRIM(genre_token) EQUALS target_genre THEN
21:                 INCREMENT genre_count BY 1
22:                 
23:                 // Step 5: Selection and tie-breaker (strict inequality)
24:                 IF movie.IMDB_Rating > best_rating THEN
25:                     SET best_rating TO movie.IMDB_Rating
26:                     SET best_movie TO movie.Series_Title
27:                 END IF
28:                 BREAK // Prevent duplicate counting for repeated tags
29:             END IF
30:         END FOR
31:     END FOR
32:     
33:     // Step 6: Output results or non-existence notification
34:     IF genre_count EQUALS 0 THEN
35:         PRINT "Genre not found in dataset: " + target_genre
36:     ELSE
37:         PRINT "Genre: " + target_genre + " | Movies Counted: " + genre_count
38:         PRINT "Top Movie: " + best_movie + " | Rating: " + best_rating + "/10"
39:     END IF
40: END FUNCTION

Design Decisions & Motivations

  • Count: We decided to use count for matching movies so that the user can see how many movies matched the search and how many movies were considered when finding the highest-rated one. The other option was having no count, which would give the user less information.
  • User Genre Selection: A decision was made to let the user select the genre to have a focused result and also to keep the algorithm simple and manageable for me. The other alternative would be to show the highest-rated movie for each of the genres in the dataset..
  • Best Rating: Best rating starts at 0 because every IMDb rating in the dataset is above 0. If the rating started at a higher number, it would prevent the algorithm from selecting a movie with a lower rating even though it could be the highest-rated movie in the selected genre.
  • Multiple Genres: We decided as a group to check all genres listed for each movie. This allows more movies to match the search. For example, a movie listed as both Romance and Drama can be selected when the user selects either genre. The alternative we discussed was to only use the first listed genre, which would make the algorithm simpler but could leave out movies that match the user’s selected genre.
  • Tie Rule: We made the decision that if two movies have the same highest rating, the algorithm will keep the first one found in the dataset. I made this decision to give the algorithm a clear and consistent tie rule without adding extra steps. The other option is displaying both movies or coming up with another rule to choose which movie to display when ratings are equal.
