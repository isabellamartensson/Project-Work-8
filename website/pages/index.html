About the Project

When exploring vast cinema archives, viewers often face choice paralysis. Our project addresses a concrete cultural analytics need: Given any movie genre, what is the single highest-rated film in the curated IMDb catalog, how many films represent that genre, and what makes this ranking statistically sound?

Project Workflow in Five Steps

  1. Step 1: Conceptualization: Formulated the problem of deterministic, genre-specific movie recommendation and conceptualized a relational tabular model mapping multi-genre attributes.
  2. Step 2: Curate & Clean Dataset: Curated 99 high-rated items (exceeding the 50-item minimum requirement), fixed UTF-8 character encoding artifacts, and validated CSV well-formedness.
  3. Step 3: Algorithm Design: Authored a 38-line formal pseudocode and Python script with iteration, tokenized string selection, 0.0 baseline initialization, and deterministic tie-breaking.
  4. Step 4: Web Application: Designed this 4-page responsive web platform complete with real-time client-side algorithmic simulation and data exploration.
  5. Step 5: GitHub Publishing: Packaged the codebase into a clean Git repository and deployed it publicly on GitHub Pages.
