What Does the Dataset Describe?

Our curated dataset, IMDB_DATASET_clean.csv, describes 99 acclaimed feature films selected from the Internet Movie Database (IMDb). The dataset provides rich cultural and production metadata spanning eight decades of cinematic history (1931–2020), including directorial credits, leading cast members, critical acclaim scores, and multi-genre taxonomies.

This dataset easily satisfies and exceeds the assignment specification requiring a minimum of 50 well-formed items.

Dataset Overview at a Glance
  • Total Curated Items: 99 feature films (exceeds the 50-item minimum)
  • Attribute Count: 16 structured metadata fields
  • File Formats: Validated UTF-8 Comma-Separated Values (.csv) and serialized .json
  • Primary Analytics Fields: Series_Title, Genre, IMDB_Rating
  • Download Dataset: Download IMDB_DATASET_clean.csv

Data Model & Schema

Below is the formal schema defining the 16 metadata attributes recorded for each cinematic item:

Column Name Data Type Description & Role in Algorithm
Series_Title String (Text) Official release title of the film; returned as the algorithm's winning recommendation.
Genre String (Comma-separated) One or more genre tags (e.g., "Action, Crime, Drama"); split and trimmed by the algorithm.
IMDB_Rating Float (Numeric 0.0–10.0) User-weighted IMDb rating score; serves as the numerical sorting key.
Released_Year Integer (Year) Original theatrical release year (spans 1931 through 2020).
Certificate String (Rating Code) Content classification rating (e.g., A, UA, U, PG-13, R, Passed).
Runtime String (Minutes) Total running duration formatted with unit suffix (e.g., "142 min").
Overview String (Narrative) Concise narrative synopsis describing the core dramatic plot.
Meta_score Float (0–100) Normalized Metacritic critic assessment score.
Director String (Name) Principal film director credit (e.g., Christopher Nolan, Francis Ford Coppola).
Star1, Star2, Star3, Star4 String (Names) Top four billed lead actors/actresses.
No_of_Votes Integer Total quantity of registered user votes submitted on IMDb.
Gross Float / Currency Cumulative worldwide or domestic box-office earnings.
Poster_Link URL (HTTP Link) Direct hyperlinked image asset representing the official theatrical poster.

Data Curation, Cleaning & Validation

Curatorial Decisions & Cleaning Interventions:

  • Mojibake & Character Encoding Repair: The raw Excel export suffered from Latin-1/CP1252 decoding artifacts where UTF-8 characters were garbled.   • Multi-Valued Genre Modeling: Rather than forcing films into an artificially reductive single-genre category or relying on brittle substring searches (which cause false positives like "Music" matching "Musical"), we preserved composite comma-separated genres and implemented exact token splitting in the algorithm.
  • Text Sanitization & Whitespace Trimming: Removed trailing ellipsis artifacts (such as "See full summary »") and trimmed leading/trailing spaces across all text columns.
  • Dataset Validation: The final IMDB_DATASET_clean.csv was checked for RFC 4180 CSV compliance, ensuring proper field escaping and quote delimiters across all 99 rows.
